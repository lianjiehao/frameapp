组件提供方用途与信息
FlutterGoogle / Flutter 开源项目界面与本机运行。渲染与运行所需的设备环境；本版本不主动上传
cameraFlutter 官方插件相机预览与拍照。系统相机画面、临时照片、相机设备信息；本机处理
galGal 开源项目把拍下的照片保存到相册。你拍下的照片、系统保存权限状态；本机处理
sensors_plusFlutter Community / Plus Plugins显示水平与仰俯提示。加速度／重力方向；本机即时使用
shared_preferencesFlutter 官方插件记住政策同意与提示状态。政策版本、同意状态和提示状态；本机保存
permission_handlerBaseflow 开源项目查询和申请相机权限、打开系统设置。系统权限状态；本机使用
webview_flutterFlutter 官方插件在 App 内渲染说明页面。应用内 HTML 与系统 WebView 环境；本机展示
url_launcherFlutter 官方插件打开用户选择的 GitHub 或邮件链接。你主动选择的链接；由系统处理

部分组件包含平台实现与间接依赖，均用于上述功能。本版本没有广告、统计、推送或云端照片识别组件。随功能变化会同步更新清单。
