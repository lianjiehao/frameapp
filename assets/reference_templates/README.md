# Reference photos / 参考照片

This directory contains 139 approved reference photos packaged on 2026-10-24 for FRAME's built-in pose library.

The user explicitly confirmed authorization to redistribute these photos in FRAME's built-in pose reference library. The photos remain third-party material and are not relicensed under FRAME's MIT license. Do not reuse them outside that confirmed purpose without checking the applicable permission.

The bundled JPEGs have a maximum long edge of 1200 pixels. `catalog.json` records each source ID, category, gender, source dimensions, byte size and SHA-256 digest. The source IDs and converted image digests are unique. Browsing, filtering, display and overlay selection work offline. The two-column library displays these local images without an additional thumbnail copy or a fixed 300-pixel decode limit, and builds cells as they enter the scroll viewport.
