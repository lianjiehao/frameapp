# 姿势参考图拍摄

[English](pose.md) | [简体中文](pose.zh-CN.md)

摆姿模式将参考图按预览高度适配并左右居中。选图后即可按主快门拍照，不运行人体识别、不要求对齐保持，也不再显示单独的「直接拍照」。快门上方同一行分成两个独立描边区域：左侧为参考图缩略图与切换图标，右侧为透明度与镜像。去掉眼睛按钮，透明度调至 0 即可隐藏叠图。下方依次为「重新开始」、居中快门与最近照片图标。滤镜在选图前仍显示于首页，选图后移入更多菜单。「重新开始」只清除当前选择。摆姿首页与构图首页使用相同底部间距、滤镜显示及后置相机变焦控件。参考图不会写入成片。构图仍要求对齐保持一秒；未就绪时「直接拍照」位于快门下方，真实相机右侧显示照片图标，练习模式该位置显示「自动对齐」。

## 使用流程

1. 在原生相机页面，用左上角的文字页签切换「构图模式 / 摆姿模式」。练习模式（包括 Web 和 `DEMO_MODE=true` 构建）只显示「构图模式」；从摆姿进入练习会切回构图。构图分为「取景 / 构图 / 拍照」三步，摆姿分为「选图 / 摆姿 / 成片」三步。首次进入摆姿时，「选择参考图」上方显示带箭头的悬浮气泡，可点气泡直接打开图库或点关闭收起；入场动画遵循系统减少动态效果设置，展示记录保存在本地偏好设置中，切换方式或重启后不再重复。
2. 在「选图」步骤中，从底部图库面板选择内置照片，或通过系统图片选择器导入一张图片。可先将外部应用中的参考图保存到手机；当前不接收分享链接、剪贴板或远程图片地址。取消图库或系统选图不会改变当前参考图。未选图的初始页显示当前滤镜，并支持与构图相同的后摄变焦。
3. 选图后直接进入「摆姿」，参考图保持原始比例自动撑满预览区高度并左右居中；超出预览宽度的部分居中裁切，较窄的图片两侧保留相机画面。无需手动拖动、缩放、复位或锁定，也没有「开始摆姿」确认。透明度和镜像可在拍摄时直接调整。
4. 摆好姿势即可按主快门，不受人体检测状态限制。上方用缩略图和切换图标更换参考图，与透明度、镜像调节区分成两个独立区域。下方为「重新开始」、快门与最近照片图标；滤镜位于更多菜单，透明度调至 0 可隐藏参考图。真实后摄在选图前后都支持倍率档位、滑动拨盘和双指变焦；前摄、练习图片与 Web 不显示虚构倍率。
5. 拍摄出照片后才进入「成片」。两种模式共用干净成片、照片查看、保存及保存失败重试流程；拍摄和保存期间禁止切换方式。「再拍」保留已选参考图并回到第二步。系统返回优先关闭图库或其他面板；在摆姿页面返回会清除当前选择并直接回到选图状态，不删除图库原图。

构图首页和摆姿首页使用相同底部结构及间距，预览维持居中 3:4。摆姿拍摄使用自然高度的两行紧凑底栏，不再固定占用 192 像素，给预览留下更多空间。放大字号时控件可自然增高。悬浮导入指引不占布局空间。

图库包含 139 张内置参考照片，可按类别、性别和收藏筛选；内置照片和筛选可离线使用，收藏保存在本机。个人图库仍单独提供最近导入、收藏和删除。清除选择只移除当前叠加，不删除图库记录。

图库始终使用两列列表，直接显示内置 JPEG 或个人导入的规范化 PNG，不再额外按 300 像素解码。类别、性别和收藏栏固定在图片列表上方，仅图片区域纵向滚动，切换筛选后列表回到顶部。单一 Sliver 滚动容器按需构建图片；打开面板无需等待个人图库磁盘读取。导入入口不保留按下背景或水波纹，避免面板下方出现残影。

两种模式均在成片页显示照片图标；摆姿选图后的快门右侧也显示照片入口，本次会话有照片后启用，关闭查看页后保留参考图及调整；构图的真实相机引导页快门右侧也保留图标；练习模式该位置显示「自动对齐」。点击全屏查看最近一张照片，支持双指缩放、关闭和系统返回。返回后保留相机步骤、成片及保存状态。撤回同意关闭查看页并清除内存照片；不读取或删除系统相册照片。

参考图保持原始比例，随预览区大小自动按高度撑满并左右居中，超出左右边界的内容被裁切。镜像由用户单独控制，切换前后镜头不自动翻转参考图。滤镜作用于相机画面和成片，不作用于参考图。参考图、文字和构图辅助线都不会写入拍摄的 PNG；保存失败保留成片供重试。

## 手动拍照与限制

摆姿是手动参考图辅助功能，相机流程不启用人体检测，不显示关键点提示、进度圆环或人体对齐门槛。相机初始化、正在变焦、等待倍率更新、拍摄、后台暂停与隐私状态仍约束快门。构图原有的对齐和画面新鲜度检查保持不变。保留的检测模块具有独立测试及[模型来源与许可](../assets/models/README.md)，其结果不控制当前界面。

## 本地数据与权限

图片选择器使用 `image_picker`，仅在用户点击导入后打开，不扫描相册，也不为导入请求整库读取权限。iOS 保留插件要求的选图用途说明，设置 `requestFullMetadata: false`；保存照片仍使用现有的仅添加照片授权。Android 使用插件提供的系统图片选择路径，不新增存储或媒体读取权限。若系统在选图时回收应用，下次主动点击导入时先尝试恢复上次已选图片，不在启动时自行读取。相机与传感器仍受隐私同意和原有按需授权约束。

选中图片在本机解码，按比例缩小至最长边 1600 像素，再编码为 PNG，去除原文件元数据；只使用动态图的首帧。输入限制为 25 MiB。`crypto` 计算规范化 PNG 的 SHA-256 进行去重，`path_provider` 提供应用私有存储位置。手机图库最多保留 20 张，超限时仅淘汰最旧的未收藏图片；全部收藏时需先删除。删除只移除私有副本，不删除系统相册原图。收藏状态和图片在下次启动仍可打开，但不自动选中图片。镜像与透明度只在本次相机会话保留。

内置目录包含 139 张已审核的参考照片，于 2026-10-24 打包。照片和类别/性别元数据随应用分发；浏览和筛选不访问服务器；选图只更新本机参考图叠加。个人导入继续保持原有本机处理方式。Web 保持练习环境，不打开浏览器相机；个人导入仅保留在当前页面会话。撤回隐私同意停止相机会话并清除内存中的成片及当前参考图，但不会删除随应用内置的照片、个人图库副本或系统相册成片。

## 实现位置

- `lib/main.dart`：姿势入口、图库面板、调整控件及手动快门。
- `lib/services/references.dart`：按需选图、解码规范化、去重、收藏、选择、镜像和透明度状态。
- `lib/services/reference_store_*.dart`：手机私有文件和索引；Web 会话内存实现，使用条件导出。
- `lib/services/reference_catalog.dart` 与 `assets/reference_templates/`：内置参考照片、目录元数据及本地类别/性别筛选。[来源和授权记录](../assets/reference_templates/README.md)。
- `lib/ui/reference_library.dart` / `reference_overlay.dart`：图库与仅供取景的图像叠加层。
- `lib/ui/pose_controls.dart` / `pose_import_hint.dart`：选图后手动拍摄的控件、紧凑底部及锚定到导入按钮的悬浮指引。
- `lib/ui/camera_zoom_dial.dart`：摆姿选图前后与构图共用的后置相机变焦拨盘。
- `lib/ui/photo_viewer.dart`：两种模式共用的全屏可缩放成片查看页。
- `lib/services/coach.dart`：两种方式共用相机和干净成片路径；摆姿使用手动参考图，不启用人体推理或构图推荐。
