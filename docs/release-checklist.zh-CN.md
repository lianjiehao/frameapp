# 真机与构建检查

[English](release-checklist.md) | [简体中文](release-checklist.zh-CN.md)

验证相机相关改动或准备分发时使用。记录提交 SHA、设备、系统版本与实际结果；未验证的平台明确注明。

## 真机检查

- [ ] 同意隐私政策前不启动相机；拒绝权限后仅在主动重试时再次请求。
- [ ] 主体点选、移动、跟丢与重选正常；检查低光、晃动和快速移镜。
- [ ] 前后摄、画面裁剪、方向、引导拍照与直接拍照符合预期。
- [ ] 照片可保存到相册；空间不足或保存失败时保留照片并支持重试。
- [ ] 后台恢复、政策页返回正常；撤回同意停止相机与分析，清除内存照片。
- [ ] 帮助与政策页面本地显示，外部链接仅在用户操作后打开。

## 分发前（按需）

- [ ] 必需检查通过；产物对应已验收提交，版本与构建号正确。
- [ ] 使用自己的签名，产物不含凭据；政策内容与联系信息符合实际版本。
- [ ] 保留 MIT 与第三方声明，新增素材具备分发授权。
